# Frameflow

Frameflow 官方安装包、稳定版更新与版本说明。

## 下载安装

[下载 Windows 最新安装包](https://github.com/2570654286/drama-clip-studio/releases/latest/download/Frameflow.Desktop-stable-Setup.exe)

[查看更新说明及历史版本](https://github.com/2570654286/drama-clip-studio/releases)

支持 Windows 64 位。安装包集成运行环境及 GPU / CPU 相关组件，无需另行安装 Python 或 FFmpeg。显卡加速取决于设备与驱动支持，软件保留 CPU 兼容路径。

安装程序未购买 Windows 发布者签名证书，首次安装可能提示未知发布者。请从本仓库的 Releases 下载；软件通过 Ed25519 签名和完整包校验验证后续更新。

## 自动更新

安装支持自动更新的版本后，软件会在启动后及运行期间定期检查稳定版，后台下载并验证。默认下次启动时安装，也可在软件更新设置中选择空闲后重启更新。任务运行或暂停时不会安装，更新前保存工作。

关闭网页不会退出后台；可使用软件中的“退出软件”入口保存并退出。

成员下载公开安装包及更新无需 GitHub 账号。旧的无自动更新版本需要先安装一次新版。本仓库只发布安装包及更新资料，不存放原视频、字幕、用户密钥或源代码。
